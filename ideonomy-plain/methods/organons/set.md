# Organon: set

A membership-defined collection where inclusion, exclusion, overlap, and cardinality carry meaning.

## Procedure

1. Define membership rule and scope.
2. Enumerate members and boundary cases.
3. Compare intersections, unions, differences, and subsets.
4. Record whether the collection is exhaustive, sampled, or provisional.

## Provenance

Gunkel’s glossary lists sets among organons; procedure is an adaptation.
