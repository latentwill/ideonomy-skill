# Organon: simulation

A runnable or mental model whose states change under rules and inputs.

## Procedure

1. Define state variables, rules, initial conditions, and outputs.
2. Run baseline and perturbed cases.
3. Inspect sensitivity, emergent behavior, and invalid states.
4. Compare outputs with observations and state model limits.

## Provenance

Gunkel’s archive names simulations as organons; procedure is an adaptation.
