# Organon: fractal

A recursively repeated structure whose relation can be inspected across scales.

## Procedure

1. State the generating rule and base case.
2. Instantiate at two or more scales.
3. Compare invariants, changes, and boundary effects.
4. Stop when new scale adds no new information or the analogy breaks.

## Provenance

Gunkel’s Bright Green discussion names fractals and scale variation; procedure is an adaptation.
