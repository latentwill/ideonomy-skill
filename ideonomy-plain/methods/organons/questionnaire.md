# Organon: questionnaire

A structured prompt set whose answers populate dimensions, cases, or gaps.

## Procedure

1. State the inquiry and respondent or evidence scope.
2. Order prompts from definitions to discriminating details.
3. Allow unknown, inapplicable, and disputed answers.
4. Aggregate responses while preserving outliers and provenance.

## Provenance

Gunkel’s glossary lists questionnaires among organons; procedure is an adaptation.
