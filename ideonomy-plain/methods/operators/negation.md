# Negation

List the working definition's core properties. For each, construct a contrast: absence, reversal, contrary value, or a different actor. Name which contrast you used; these are not interchangeable logical complements. Show each changed property and resulting idea, preserving constraints. Examine coherence and revealing failures. A coined name is not evidence of an established phenomenon. Reversing the contrast need not recover the original; “partial involution” is an illustrative expectation, not a proven algebra. Ordinary substitution can also change incidental properties.
