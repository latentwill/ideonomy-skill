# Summarize, simplify, or epitomize

Compress an organon without losing distinctions needed for inspection. Use this after the requested exploration is complete; it does not replace the full exploration by default.

## Procedure

1. State purpose and audience.
2. Group repetitions; retain mechanism, edge cases, uncertainty, and provenance.
3. Preserve representative examples per branch.
4. Compare summary with source and list omissions.
