# Interaction

Study how two or more organons alter one another when applied together.

## Procedure

1. State each organon’s input and output grammar.
2. Apply them separately, then in both possible orders.
3. Record synergies, conflicts, emergent cells, and order effects.
4. Preserve a failure when it reveals an incompatible assumption.

## Provenance

Gunkel’s Yellow Volume glossary names interaction among organon relations.
