# Exemplify and re-exemplify

Make an abstract structure testable by instantiating it in varied cases.

## Procedure

1. Give a positive example and map each defining feature.
2. Add a counterexample, near miss, and boundary case.
3. Re-instantiate the structure in another domain or scale.
4. Record which features survive translation.
