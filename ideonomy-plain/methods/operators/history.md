# Reconstruct history

Trace origins, transitions, and path dependence.

## Procedure

1. Set the time window; distinguish documented events from reconstruction.
2. Mark origins, forks, accelerations, reversals, dormant periods, and survivals.
3. Identify causes, constraints, and alternatives at each fork.
4. Ask what would differ if one transition had not occurred.
