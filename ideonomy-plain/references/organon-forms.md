# Archive organon forms

This is a source-linked inventory of additional forms named in Gunkel’s archive. It is a reference for deliberate selection, not a claim that every form is a canonical or distinct primitive.

## Additional forms

- **set** — membership-defined collection; use [organons/set.md](../methods/organons/set.md).
- **chain** — linked sequence of causes, events, or transformations; use [organons/chain.md](../methods/organons/chain.md).
- **series** — ordered succession where position or progression matters; use a list or procedure and preserve order.
- **ring** — closed relational sequence; use [organons/ring.md](../methods/organons/ring.md).
- **circuit** — directed route with operational flow, gates, or feedback; use [organons/circuit.md](../methods/organons/circuit.md).
- **radiation** — one center with multiple outgoing relations; use a graph or map with a declared center.
- **network** — many-to-many nodes and relations; use graph.md and permit multiple parents.
- **fractal** — recursively repeated structure across scales; use [organons/fractal.md](../methods/organons/fractal.md).
- **plexure** — densely interwoven structure whose crossings and bundles carry information; use graph plus a map when spatial crossings matter.
- **cellular automaton** — grid of local states updated by rules; use [organons/simulation.md](../methods/organons/simulation.md) with a periodic-grid state space.
- **myriorama** — modular scene or sequence assembled from interchangeable parts; use list plus combination and permutation.
- **dualities and asymmetry displays** — paired or mirrored structures; use matrix or chart with an explicit reversal/comparison rule.
- **ideogram / symbolic notation** — compact symbols whose relations encode the idea; use notation.md.
- **index** — retrieval-oriented pointers from terms or features to locations; use dictionary.md plus source IDs.
- **file / dossier** — bounded case collection with evidence and annotations; use list or atlas plus provenance fields.
- **questionnaire** — structured prompts whose answers populate dimensions or gaps; use [organons/questionnaire.md](../methods/organons/questionnaire.md).
- **scenario** — conditional world-state or narrative used to test consequences and plans; use [organons/scenario.md](../methods/organons/scenario.md).
- **strategic game** — turn-based or adversarial model exposing choices and counter-moves; use state-machine plus evaluation.
- **simulation** — executable or mental model whose state changes under rules and inputs; use [organons/simulation.md](../methods/organons/simulation.md).
- **brainstorming session** — social procedure that generates, combines, critiques, and filters candidates; use procedure plus combination and critique.
- **book / encyclopedia / library** — nested collections of organons; use atlas plus index and explicit scope.
- **globe / atlas-world** — navigable spatial model where zoom and projection alter visibility; use atlas plus map and scale.
- **blackboard / workspace** — shared evolving surface for temporary structures and annotations; use list, chart, or map with revision IDs.
- **computer program** — executable organon that applies rules, searches combinations, or generates views; use procedure or simulation and record the algorithm.

## Selection notes

Choose a form by its load-bearing relation. A chain requires succession; a ring requires closure; a network permits multiple relations; a cellular automaton requires local update rules; a scenario requires conditional world assumptions. If a form is only a metaphor for an existing graph, tree, procedure, or simulation, use the existing form and record the metaphor rather than multiplying names.

## Provenance

The forms are paraphrased from Patrick Gunkel’s *Yellow Volume* glossary entry “Organons” and the *Bright Green Volume* discussion of knowledge meta-structures. The archive names many forms, including sets, lists, charts, diagrams, maps, ideograms, indexes, files, books, dictionaries, encyclopedias, libraries, globes, questionnaires, scenarios, strategic games, simulations, and programs, as well as trees, chains, series, networks, radiations, lattices, matrices, rings, circuitries, fractals, plexures, cellular automata, myrioramas, dualities, and asymmetries. The archive is static and explicitly provisional; this inventory is therefore comprehensive only within those inspected passages, not universal.
