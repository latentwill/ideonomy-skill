# Naming remix notes from session

Use this when the user wants naming output, especially for course/workshop titles.

## Key correction

- Labels like `Arc`, `Rhythm`, and `Vector` may be **concept buckets** in the naming process, not literal title words.
- Do not place those bucket labels into the final title unless the user explicitly asks for them.

## What worked

- Prefer actual name families such as:
  - Blueprint
  - Lab
  - Academy
  - Method / System
  - Workshop / Bootcamp
- Let the subtitle carry the promise.
- If the user asks for a live event, include `live workshop` in the subtitle or format line.
- Keep the title playful, short, and memorable; keep the subtitle close to the core promise.

## Useful title shapes

- `Start, Shape, Ship` + `A live workshop for building something real, useful, and shippable`
- `Idea to Impact Workshop`
- `Builder Blueprint`
- `Useful Work Lab`

## Avoid

- Using conceptual buckets as final title words by default.
- Over-explaining the naming process when the user wants the clean result.
- Generic filler like `Build with AI` or `Create with AI` when more original phrasing is possible.
