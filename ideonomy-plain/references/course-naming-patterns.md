# Course naming patterns from the Start, Shape, Ship session

## What the user wanted
- Brandable, simple, outcome-first naming.
- Fun and creative, not stiff or generic.
- Live workshop signal should be explicit in the subtitle when relevant.
- The title can be playful; the subtitle should stay close to the promise.
- Avoid literal use of design-bucket labels when those are only concept buckets.

## Research-backed name families that repeated
- Blueprint
- Lab
- Academy
- Method / Protocol
- Workshop / Bootcamp

## Useful patterns
- Brand word + shell: `Builder Blueprint`, `Useful Work Lab`
- Action trio: `Start, Shape, Ship`
- Promise-close subtitle: `A live workshop for building something real, useful, and shippable`
- Live-format cue: explicitly say `live workshop` when format clarity matters

## Pitfalls
- Don’t turn concept buckets into literal title words unless the user says to.
- Don’t let the subtitle drift away from the actual promise.
- Don’t over-explain the title if the user wants the name to feel fresh and brandable.
