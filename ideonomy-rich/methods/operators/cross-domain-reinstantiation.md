# Cross-domain re-instantiation

Start with an abstract relationship, using abstraction-lift if needed. Choose a different relevant domain, including an unfamiliar direction when useful. Map each source role and relation into the target, then state the concrete candidate. Record what the target reveals or suggests transferring back, plus at least one point where the analogy breaks. Verify domain claims before relying on them; do not invent established terminology or novelty. Repeat across distinct domains only within the requested scope.

Adapted from Gunkel and Kind; see [sources](../../references/sources.md).
