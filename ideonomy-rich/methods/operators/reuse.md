# Reuse an organon

Apply an existing list, chart, dimension, or procedure to a new subject and audit fit.

## Procedure

1. Name source organon, scope, and grammar.
2. Map source slots to target slots without changing meaning.
3. Mark empty, forced, and overloaded slots.
4. Revise only structural mismatches and record the revision.

## Provenance

Gunkel’s Way 20; recursive reuse is central to the archive.
