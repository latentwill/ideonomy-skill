# Model, simulate, logicize, or conceptualize

Represent dependencies and behavior without confusing model with reality.

## Procedure

1. State entities, states, relations, rules, parameters, and initial conditions.
2. Build the smallest useful model.
3. Vary inputs; inspect sensitivity and emergent behavior.
4. Compare outputs with observations and list model limits.

## Provenance

Gunkel’s Way 16; outputs remain model-relative.
