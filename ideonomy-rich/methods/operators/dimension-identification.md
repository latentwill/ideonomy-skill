# Dimension-identification

Ask what can differ between two versions while both remain instances of the working idea. Name each axis and list meaningful possible values; a fixed constraint is not a varying axis. Test an alternative value through substitution. Record dependencies between axes instead of assuming independence. Select axes that cover the requested breadth and expose different mechanisms, not a fixed quota. Dimension prompts suggest questions, not an exhaustive taxonomy. These axes feed substitution, negation, and cross-products.

Adapted from Gunkel and Kind; see [sources](../../references/sources.md). [Examples](../../references/operator-examples.md#dimension-identification) are optional.
