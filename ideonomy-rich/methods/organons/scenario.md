# Organon: scenario

A conditional world-state used to test consequences, plans, and alternatives.

## Procedure

1. State actors, initial conditions, horizon, and uncertainty.
2. Build continuation, stress, and reversal scenarios.
3. Trace decisions and consequences under each.
4. Record triggers that would distinguish scenarios in reality.

## Provenance

Gunkel’s archive names scenarios among organons; procedure is an adaptation.
