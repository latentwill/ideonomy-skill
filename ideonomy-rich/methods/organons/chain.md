# Organon: chain

A linked sequence of causes, events, or transformations where adjacency and direction carry meaning.

## Procedure

1. Name link relation and start/end scope.
2. Enumerate each link and its precondition.
3. Mark branches, loops, breaks, and bottlenecks.
4. Test whether changing one link changes downstream results.

## Provenance

Gunkel’s glossary and “What Ideonomy Can Do” name chains; procedure is an adaptation.
